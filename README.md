# onekey-wallet-skills

OneKey wallet skills for AI coding assistants.

## Installation

```text
/plugin marketplace add OneKeyHQ/onekey-wallet-skills
/plugin install onekey-wallet-skills
```

## Skills

| Skill | Path | Purpose |
| --- | --- | --- |
| `onekey-market` | `skills/onekey-market/` | Token discovery, prices, charts, and market research |
| `onekey-security` | `skills/onekey-security/` | Token safety checks, transaction simulation, and risk reviews |
| `onekey-swap` | `skills/onekey-swap/` | Swap quotes, execution workflows, and swap status |
| `onekey-wallet` | `skills/onekey-wallet/` | Wallet balances, transfers, history, and wallet management |

Learn more about OneKey at https://onekey.so.
